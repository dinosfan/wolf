# 한밤의 늑대인간 · Daybreak 확장판

일반판(main)과 독립적인 daybreak 브랜치 및 Render 서버입니다. 일반판 주소와 방은 공유되지 않습니다.

## 사용
닉네임 → 방 만들기 → 인원(3~10명) → 역할 N+3장 선택 → 게임 시작. 확장판 추천 구성 버튼과 봇 채우기를 지원합니다. 우두머리 늑대를 넣으면 별도 가운데 늑대 1장이 자동 추가됩니다.

기본 12종에 파수꾼, 우두머리 늑대, 신비한 늑대, 잠자는 늑대, 견습 예언자, 초자연 조사관, 마녀, 마을 바보, 공개자, 유물 관리인, 경호원 11종을 추가했습니다. ⓘ 안내에서 모든 능력과 유물 6종을 볼 수 있습니다.

밤 행동은 음성 안내 후 10초 고정입니다. 시간 초과 시 선택 행동은 생략하고 필수 복사·교환은 무작위 처리합니다. 마녀는 가운데 카드를 확인했으면 교환을 반드시 완료합니다. 한 명이 봇과 테스트할 때 빠른 진행을 켜면 사람의 선택은 직접 완료하고 나머지 대기를 줄입니다.

공식 규칙: https://cdn.shopify.com/s/files/1/0740/4855/files/Daybreak_rules_for_BGG.pdf?338=
보호막은 카드 자리의 확인·이동·유물 배치를 막습니다. 경호원은 최종 역할로 판정하며 지목한 사람의 투표·사냥꾼 사망을 막습니다. 보호받지 않는 득표 최상위 사람이 2표 이상일 때 사망합니다. 조사관은 보이는 카드의 역할만 확인하고 숨겨진 복사·변신 정보는 보지 못합니다. 유물은 낮 시작 때 소유자에게만 공개하며 역할 유물은 최종 카드 능력·승리 조건을 덮어씁니다. 침묵·수치는 화면에 안내되고 실제 말하기와 시선은 참가자가 준수해야 합니다.

## 실행·검증
Node.js 20+, npm install, npm start. npm test: 기본 게임 1,011판/승리 판정 100,000건, 확장 329판/추가 판정 25,000건, 직업별 도플갱어, 6종 유물, 보호막, 경호원, 카드 이동, 재접속, 고정 시간, 화면과 음성 완료 처리 검사.

서버 메모리에 방을 저장하므로 서버 재시작 시 방이 사라집니다. 음성은 휴대폰의 한국어 TTS를 사용합니다.
