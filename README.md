# 한밤의 늑대인간 모바일 v0.3

친구들끼리 **각자 휴대폰 브라우저**로 접속해서 플레이하는 개인용 실시간 웹앱입니다. 공식 카드 이미지/공식 음성 파일은 포함하지 않고, 규칙 로직과 자체 UI/한국어 TTS 나레이션을 구현했습니다.

## v0.3 핵심

- 3~10명 방 코드 멀티플레이
- 역할은 항상 `인원수 + 3장`
- 기본판 역할 전체 구현
  - 도플갱어
  - 늑대인간×2
  - 하수인
  - 석공×2
  - 예언자
  - 강도
  - 말썽쟁이
  - 주정뱅이
  - 불면증 환자
  - 사냥꾼
  - 무두장이
  - 주민×3
- 도플갱어의 모든 기본판 분기 구현
- 카드의 **물리적인 앞면**과 **최종 유효 역할**을 별도로 관리
- 강도/말썽쟁이/주정뱅이 카드 이동 반영
- 도플갱어 카드 이동 시 복사한 역할/승리 조건도 카드와 함께 이동
- 밤 역할 순서 자동 진행
- 선택된 역할이 가운데에 있어도 항상 동일하게 호명
- 방장 폰 TTS가 나레이션 종료와 서버 진행을 동기화
- 지원되는 모바일 브라우저에서는 밤 진행 중 방장 폰 화면 꺼짐 방지(Wake Lock) 요청
- 역할 행동이 너무 빨리 끝나도 최소 행동 시간을 두어 가운데 카드 여부가 쉽게 새지 않도록 처리
- 외로운 늑대의 가운데 1장 확인 옵션 ON/OFF
- 토론 타이머
- 자기 자신에게 투표 금지
- 동률 처형 / 최고 득표가 1표면 무처형
- 사냥꾼 연쇄 처형
- 하수인/무두장이 특수 승리 조건
- 개인별 승리 표시
- 시작 카드 → 최종 카드 → 투표 결과 전체 공개
- 네트워크가 잠깐 끊겨도 같은 세션으로 재접속
- 같은 역할 구성으로 바로 재경기

세부 룰 대조 항목은 `RULE_CHECK.md`에 정리해 두었습니다.

## 6명 기본 세팅

6명이 들어오면 고수용으로 아래 9장이 기본 설정됩니다.

- 늑대인간×2
- 하수인
- 도플갱어
- 예언자
- 강도
- 말썽쟁이
- 주정뱅이
- 불면증 환자

방장이 자유롭게 바꿀 수 있습니다.

## 가장 쉬운 실행법: 같은 Wi-Fi

한 명의 노트북/PC가 서버 역할을 하고 **실제 플레이는 전부 휴대폰**으로 하면 됩니다.

### Windows

1. Node.js 18 이상 설치
2. 압축을 풀고 `start_windows.bat` 실행
3. Windows 명령 프롬프트에서 `ipconfig` 실행
4. PC의 IPv4 주소 확인
5. 모든 휴대폰을 같은 Wi-Fi에 연결
6. 각 휴대폰 브라우저에서 예를 들어 아래 주소 접속

```text
http://192.168.0.15:3000
```

`192.168.0.15` 부분은 서버 PC의 실제 IPv4 주소로 바꿉니다.

Windows 방화벽에서 Node.js 네트워크 접근 허용 창이 뜨면 **개인 네트워크 허용**을 선택하세요.

## 수동 실행

```bash
npm install
npm test
npm start
```

서버 기본 포트는 `3000`입니다.

## 나레이션

1. **방장 휴대폰에서 `음성 테스트`를 먼저 누르세요.**
2. 방장 폰은 밤 진행 동기화를 위해 나레이션이 항상 켜집니다.
3. 다른 휴대폰은 기본 OFF이며 필요하면 보조 음성을 켤 수 있습니다.
4. 역할을 확인한 뒤 `확인 완료 · 밤 시작 준비`를 누릅니다.
5. 밤에는 역할이 호명될 때만 눈을 뜨고 자기 휴대폰을 확인합니다.
6. 방장 폰의 TTS가 끝나면 서버가 그 역할 행동 화면을 열기 때문에, 나레이션보다 화면이 먼저 진행되는 문제를 줄였습니다.

브라우저 내장 Web Speech API를 사용하므로 휴대폰마다 목소리는 조금 다를 수 있습니다.

## 인터넷으로 서로 다른 장소에서 할 때

Node.js/WebSocket 서버라서 Render, Railway, Fly.io 같은 WebSocket 지원 호스팅에 올릴 수 있습니다. `Dockerfile`과 `render.yaml`도 포함되어 있습니다.

## 테스트 상태

- `server.js`, `game-engine.js`, `public/app.js`: Node 문법 검사 통과
- `npm test`: 규칙 엔진 테스트 통과
- 이 작업 환경에서는 외부 npm 패키지 설치가 시간 초과되어 실제 Socket.IO 서버를 띄운 다기기 통합 테스트는 수행하지 못했습니다.
