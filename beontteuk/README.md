# 번뜩! ⚡ 같은 장소 모바일 단어 순발력 게임

블리츠/Anomia의 **단어 연상 속도 대결 메커니즘**에서 영감을 받은 오리지널 카드 주제/기호/UI를 사용한 웹 멀티플레이 시제품입니다. 원작 카드, 브랜드, 삽화는 복제하지 않았습니다.

## 실행

Node.js 20 이상. 외부 npm 의존성이 없습니다.

```bash
npm start
```

- 로컬 확인: http://localhost:3000
- **모든 참가자가 같은 Wi-Fi**에 연결하고 서버 실행 컴퓨터의 로컬 IP를 브라우저에 입력하면 각자의 휴대폰으로 게임할 수 있습니다 (OS 방화벽에서 TCP 3000 허용 필요).
- 인터넷으로 접속하려면 Render 등의 Node 웹서비스에 폴더를 배포하세요. `npm start`, 환경변수 `PORT`는 플랫폼 지정 값을 자동 사용합니다.

## 진행

1. 방장: 닉네임/최대 인원(3~8)/카드 수(60,96,120) 선택 후 방 생성.
2. 방 코드를 공유하고 3명 이상 입장, 모두 준비/접속 시 방장이 시작.
3. 화면에 표시된 자기 차례에 '카드 공개하기'를 누르면 모든 기기에 같은 카드가 동시에 나타납니다.
4. 두 플레이어의 맨 위 카드 기호가 같거나 현재 와일드카드 기호 쌍이면 즉시 대결. 각자 상대 카드의 주제에 맞는 단어를 먼저 외칩니다.
5. **현장 판정:** 방장이 승리자를 선택합니다. 정답을 입력하거나 마이크 음성을 자동 판정하지 않습니다.
6. 승리자는 패자의 **맨 위 카드 1장**을 자기 점수 더미에 추가하고, 밑 카드가 드러나 발생하는 연쇄 대결을 자동 처리합니다.
7. 와일드카드가 나오면 중앙의 활성 와일드로 교체, 같은 플레이어가 다시 뽑습니다. 카드가 모두 떨어지고 대결이 끝나면 획득 카드가 가장 많은 플레이어가 우승.
8. 게임 종료 후 재대결 가능.

## 구현 현황/주의

- Node 내장 HTTP API + SSE(Server-Sent Events)로 실시간 동기화. 각 참가자 인증용 임의 토큰, 턴 검증, 승리 중복 처리(듀얼 번호 체크), 새로고침/재연결 처리.
- 기호 강조, 대결/연쇄/와일드 자동 감지, 점수 및 순위 자동 계산, 모바일 적응형 카드 UI.
- 서버 프로세스 메모리의 방 상태는 재시작 시 유실됩니다. 영구 저장/멀티 인스턴스 배포 미구현.
- 연결 끊긴 참가자는 3명 이상 규칙과 별도로 자리를 유지합니다. 30초 넘게 끊긴 방장은 활성 참가자에게 위임될 수 있습니다. 방장이 아닌 참가자의 턴에서 장기 접속 끊김 시 수동 복구가 필요할 수 있습니다.
- **원작의 자동 시간측정/음성판정 불포함**, 현장에서 다수가 합의한 내용을 방장이 입력합니다.
- 7~8인/선택 카드 수는 자체 변형 규칙으로, 원작 공식 인원은 3~6인입니다.
- `npm test`로 코어 API/전체 라운드 검증.
